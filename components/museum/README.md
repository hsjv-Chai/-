# 博物馆前端

- `view.tsx`：展览搜索与分页、主展、展览/展品详情、私密草稿预览、图片对话框及分享链接。
- `admin.tsx`：策展列表与编辑器，保存草稿、上传、展品排序、版本冲突、预览确认及整场发布/下架。
- `app/museum.css`：独立展厅样式，限定于博物馆组件及 `.museum-mode`；手机导航增加第五个入口的尺寸规则供全站共用。

入口为 `app/museum/[[...path]]/page.tsx` 和 `app/admin/museum/[[...path]]/page.tsx`，由社区容器提供账户状态、导航和登录弹窗。公开与预览共用展示组件；请求复用社区 `api` / `useData`，标准链接保留整页导航。类型及纯输入模型来自 `lib/museum/model.ts`，不能导入博物馆服务端处理器。

视觉为白底、深色标题、绿色操作和开放图文网格；仅导航与图片工具栏使用轻磨砂。展品图片完整展示，网格封面允许裁切。图片查看使用原生模态 `dialog`，支持 Escape、左右方向键和具名按钮。

修改后同时检查根路径与 `/melon`，以及 1440、1024、768、390、320px。策展表单失败保留输入；遇到 409 时先复制需要保留的内容，再确认重新加载，不自动覆盖别人的修改。
