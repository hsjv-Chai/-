# 首页 UI 样板

此样板只覆盖首页，以及首页的搜索、分区、排序和分页状态。详情、编辑器、登录注册、个人页、管理、牌室和种瓜完整页面保持原样。没有新增接口、数据库迁移或第三方依赖。

参考 [大学社区论坛](https://dribbble.com/shots/15385888-Forum-dedicated-to-University-Community) 的三栏组织、白色内容表面和信息层级，使用项目自己的 🍉 品牌、中文内容与板块图标。参考已实际查看；没有移用其中的大学品牌、人物照片或外围展示背景。

## 设计变量

首页统一位于 `.home-v2` 作用域，变量以 `--home-` 开头，不覆盖全局 `--green` 等既有变量。实际定义在 [app/home.css](../../app/home.css)。后续调整需保持以下约定。

| 用途 | 当前值 |
| --- | --- |
| 页面和内容底色 | 纯白 `#FFFFFF` |
| 标题 / 正文 / 辅助文字 | `#24352C` / `#43584B` / `#627268` |
| 操作绿 / 悬停绿 | `#236B46` / `#195336` |
| 选中背景 / 西瓜红强调 | `#E8F3EC` / `#D85662` |
| 边框 / 卡片圆角 / 按钮圆角 | `#DFE7E1` / 12px / 8px |
| 导航透明材质 | 白色 80% 背景，16px 背景模糊；不支持模糊时使用白色实底 |

长正文和表单不使用模糊材质。透明集中在吸顶顶栏与手机底部导航，通过背景 alpha 表达层级，不降低整个容器的不透明度。基础文字对比度至少 4.5:1；选中、悬停、焦点和禁用状态均保留明确文字或图标线索。

正文 15px、帖子标题 20px、辅助文字至少 12px，沿用系统字体。摘要最多显示两行，完整内容保留在详情。四个分区继续分别使用广播、爆米花、显示器和咖啡杯图标及原有色彩类别。

## 布局与行为

- ≥1200px：最大宽度 1440px，208px 左导航、弹性讨论流、264px 社区看板，24px 栏间距。
- 768–1199px：双栏，社区看板转为讨论流上方的折叠入口。
- <768px：16px 页面边距、双行顶栏、分区卡片、单列快捷操作及带安全区留白的底部导航。
- 看板默认收起，用原生 `details/summary` 支持 Enter、Space 和 Tab，公开展开状态，换页后重置。桌面和折叠展示接收同一组父级数据，不新增请求。
- 热榜、精选、统计按顺序展示。发话题、种瓜、用户名和帖子链接沿用既有行为，所有路径经过现有前缀处理。
- 初次加载显示稳定骨架；列表与看板错误可重试；搜索无结果、空分区、空站、空热榜和空精选各有对应文案。无虚构填充数据。
- 首页可见操作区至少 44×44px；反馈过渡为 180ms，减少动态效果模式关闭首页动画和过渡。未引入新的页面转场动画。

## 模块入口

- `components/community/index.tsx`：首页样式作用域和既有数据装配，登录弹窗置于作用域外。
- `components/community/home-board.tsx`：共享看板；`home-states.tsx`：首页骨架与错误重试。
- `welcome.tsx` 和 `feed.tsx`：介绍、快捷操作、列表、搜索与分页；帖子项继续与个人页复用，视觉差异由首页作用域控制。

验证结果及限制见 [首页 UI 验证记录](../verification/home-ui.md)。样板通过独立分支 `codex/home-ui-refresh` 保存到 GitHub，供后续逐步调整；保持本地预览，不合入 main、不部署服务器。
