## 重复执行

```sh
npm run test:museum
npm run test:boundaries
node node_modules/next/dist/bin/next typegen
npm run typecheck
```

接口测试需先在空的隔离目录初始化并启动服务。示例数据目录名含 `museum-qa`，测试 URL 必须是回环地址；不能指向生产或演示截图目录。

```sh
export MELON_STORAGE=node
export MELON_DATA_DIR="$PWD/.sites-runtime/museum-qa"
export MELON_PUBLIC_ORIGIN=http://127.0.0.1:5202
export NEXT_PUBLIC_BASE_PATH=/melon
export MELON_TEST_URL=http://127.0.0.1:5202/melon
npm run init:ecs
# 在另一终端以同样的存储、来源与路径启动服务，监听 5202
npm run test:museum-api
# 实际停止并重启同一服务后，再使用相同环境执行
npm run test:museum-api -- --after-restart
```

首阶段保留私密检查点；重启阶段验证后删除该轮创建的数据。首次运行失败时保留隔离目录排查，不修改生产数据，也不要跳过重启直接宣称持久化通过。功能、迁移和回退说明见 [博物馆说明](../features/museum.md)。
