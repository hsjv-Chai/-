# 登录注册弹窗滚动修复

日期：2026-10-30。基于最新 `main`，在 `codex/auth-dialog-scroll` 分支实施。修复提交 `08556d4` 已推送修复分支、快进合入 main，并在本地验证后部署。接口、验证码规则和数据库均未修改。

## 行为与实现

- 取消整个弹窗的点击关闭处理，只允许关闭按钮或 Esc。发送验证码和提交过程中继续禁止关闭。
- 弹窗外框限制在可视窗口内，表单独立滚动，44×44px 关闭按钮位于固定区域。
- 弹窗打开时保存并锁定页面滚动，关闭时恢复原有内联样式、滚动位置与入口焦点。
- 使用 Visual Viewport 的高度及顶部偏移适配窗口变化；缩小时将当前输入框滚入可见区域。无此 API 时使用窗口高度。
- 手机输入框使用 16px 字号，避免 Safari 聚焦输入框时自动放大。保留原生 dialog 的模态与键盘行为。
- 表单和验证码倒计时仍由原组件状态管理；不会写入浏览器持久存储。
