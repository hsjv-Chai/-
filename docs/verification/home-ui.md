## 验证边界

本次浏览器检查基于内置 Chromium 的尺寸模拟，不等同于真实手机、Safari 或低性能设备验证。减少动态效果和无背景模糊的降级已实现，尚未在相应系统偏好及不支持模糊的浏览器中实测。没有新增整站配色、牌局规则、注册流程或服务器配置变更，也未做公网/大陆网络体验验收。
