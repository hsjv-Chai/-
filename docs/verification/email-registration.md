## 已完成

- 类型检查与模块边界检查通过；客户端不能导入邮件服务或发信适配器。
- 邮件单元测试十四项通过，覆盖别名归一化、HMAC/RPC 签名、验证码绑定/过期/五次错误、重发失败保留旧码、乱序返回、并发消费、十账号累计上限和最后名额竞争、发送限额、北京零点、事务失败回滚、生产拒绝模拟模式及适配器不自动重试。
- 原生 HTTP 邮件检查四十五项通过，涵盖必填验证、路径尾部 404、同源、限流等待头、正常注册自动登录、隐私、管理员同邮箱查询与私有模拟对象不可公开读取。
- 实际停止并重启服务后，七项邮件检查通过；账户、邮箱、会话、累计名额、已消费验证码及未完成验证码均持久化。种瓜重启检查十六项通过。
- 同一开发隔离环境的既有回归通过：论坛八十一项、路由一百零九项、账号管理三百一十项、单房间八十五项、完整牌局一千三百三十项、种瓜九十六项。
- Vinext、Node 根路径和 `/melon` 正式构建均通过。Worker 服务端产物未发现本项目 Node 文件存储实现或 SQLite 文件路径。
- 根路径正式服务四十七项检查通过：根资源与路由、Secure 根 Cookie、来源隔离与私有接口。
- `/melon` 的实际 standalone 服务二十一项生产拒绝/历史账号检查通过：生产拒绝模拟发信、不创建挑战/未验证账号/名额，缺少验证不能注册，历史账号登录、会话及公开资料隐私保持兼容。测试未使用真实发信凭证。
- standalone 完整持久化检查通过：准备旧账号夹具、图文帖子、回复、点赞和会话，实际重启同一数据目录后验证并清理。邮箱验证账户与未完成验证码另由邮件重启检查覆盖。
- 本地注册弹窗实际检查了错误验证码后的字段保留、正确验证码注册和自动登录；390 × 844 视口无横向溢出，表单可滚动，已查看移动画面。此结果不代表所有桌面/手机尺寸、键盘和辅助技术已验收。
- 已完成发信域名验证、触发类发信地址和专用 RAM 最小发送权限配置。持有人自行生成并保存凭证；公开仓库不保存真实配置。
- 使用真实适配器向持有人指定的邮箱发送一封验证码，阿里云接受请求；该真实验证码在独立存储中完成账户、名额和会话事务检查。持有人明确确认收件箱收到邮件，真实投递通过。没有向其他邮箱发信，也没有自动重发。
