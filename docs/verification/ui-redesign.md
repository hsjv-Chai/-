# 论坛 UI 改版记录

日期：2026-10-27。参考 [Tomasz Osowski 的大学社区论坛设计](https://dribbble.com/shots/15385888-Forum-dedicated-to-University-Community) 的侧栏、讨论流、信息卡和浅紫灰配色，结合本项目内容重新实现，没有使用参考图中的人物照片、联系方式或品牌素材。

## 已实现

- 桌面保留三栏工作区，平板收为双栏，手机使用单列、分区菜单及底部导航。
- 帖子改为独立白色卡片，突出标题、作者、正文摘要、分类和讨论入口；保留置顶、精选、演示标记、图片与互动计数。
- 首页缩短介绍区域，提供快速发帖和种瓜小组件，让讨论内容更早进入视野。
- 保留 🍉、热点现场、娱乐吃瓜、科技互联网、生活杂谈及对应图标/颜色；牌室保留扑克牌与游戏名称，种瓜保留瓜苗、七阶段成长及收获展示。
- 社区样式归入独立模块；账户、帖子、牌局、签到 API 与数据库结构没有更改。所有预览内容来自隔离目录内的虚构演示数据。

## 实际验证

- 类型检查和客户端依赖边界检查通过。
- Next.js 根路径及 `/melon` 正式构建通过，Vinext/Worker 构建通过。
- 独立测试数据库的论坛接口 81 项、统一 API 路由 109 项断言通过。
- 本地浏览器实测分区筛选、跳转后菜单收起、发帖登录入口、登录弹窗 Escape 关闭、搜索框 Enter 提交、帖子详情、图片放大与 Escape 关闭。
- 浏览器检查桌面三栏及手机单列；320px、390px、820px 的页面内容宽度均未超出视口。手机牌室扑克元素和种瓜插画已目视检查。
- 本轮不对真实公网连接或已部署服务器作验收结论；没有部署、改动 DNS 或证书。

实现入口见 [社区模块说明](../../components/community/README.md)。
