# 注册邮箱验证

社区认证入口 `lib/community/auth.ts` 调用此模块；HTTP 路径与同源保护仍在统一 API 入口。

| 文件 | 职责与依赖 |
| --- | --- |
| `model.ts` | 邮箱归一化、验证码生成、HMAC 与阿里云请求签名。纯函数可由客户端导入，不读取配置或存储。 |
| `provider.ts` | HTTPS 发信适配器及配置校验；本地开发模拟收件箱。不允许客户端导入。 |
| `service.ts` | 原子发送限额预留、验证码生命周期、注册事务；依赖共享数据库和身份工具。不允许客户端导入。 |

生产只接受阿里云成功发送的验证码。验证码消费、累计名额、账户、会话和集中注册标记在同一数据库批处理中完成。迁移中的触发器进一步保护邮箱绑定和累计名额。

发送前以数据库时间预留额度，失败仍计数；重发失败保留旧码。延迟返回的旧发送请求不能覆盖较新的成功验证码。不要在业务代码中添加自动重试、明文日志或注册降级路径。

验证：`npm run test:email`、`npm run test:email-api`；运行条件见 [开发指南](../../docs/development.md)，接入见 [邮件部署说明](../../deploy/mail/README.md)。
